El cambio de paradigma

De las ruedas a las patas

  • Propiocepción: El robot "siente" el estado de sus articulaciones.
  • Navegación real: Superación de escaleras y entornos no estructurados.
  • Más que código: Biomecánica, física y IA en un solo dispositivo.

3 Niveles de Integración

Un recurso que evoluciona con el alumnado.

Nivel 1: Lógica
1º - 3º ESO
Herramienta: Programación por bloques.
Aplicación: Secuencias de movimiento, bucles de patrulla y LEDs.
Enfoque: Asentar el pensamiento computacional sin frustración sintáctica.
Nivel 2: Control IoT
4º ESO - 1º Bachillerato
Herramienta: Control vía Wi-Fi y scripts sencillos.
Aplicación: Envío de comandos en red local y lectura de sensores.
Enfoque: Transición al código texto (Python) y arquitectura cliente-servidor.
Nivel 3: IA y Visión
2º Bachillerato y FP
Herramienta: Python, C++ y APIs nativas del robot.
Aplicación: Procesamiento de imagen, LIDAR, rutinas de IA.
Enfoque: Preparación directa para perfiles profesionales tecnológicos.

Llevándolo a Centros

1. Formación Docente

Diseñar itinerarios escalonados. Empezar por control directo y avanzar a código para evitar frustración.

2. Logística de Aula

Gestión de baterías (1-2h), calibración y protocolos de seguridad con grupos grandes.

Tip Avanzado: Unitree Go2 tiene un SDK oficial para Python (llamado unitree_sdk2_python) que es fantástico para la educación porque permite controlar un hardware muy complejo con muy pocas líneas de código.

El sistema funciona sobre una arquitectura de red (usando un protocolo llamado CycloneDDS). Básicamente, conectas el ordenador al robot (por Wi-Fi o cable de red), inicializas la comunicación y le envías comandos.
